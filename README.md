# Andy Zhang

Personal website: https://middleclicker.github.io/

Static HTML and CSS. No JavaScript or build step.

## Preview

```sh
python3 -m http.server 4173
```

Open http://localhost:4173.

## Edit and publish

Edit `index.html` for content and `index.css` for styling. Update the stylesheet version in both HTML files when changing CSS. Push to `main` to publish through GitHub Pages.

The site uses the self-hosted DM Sans font; its license is in `assets/fonts/DM-Sans-OFL.txt`. Assets from previous designs remain in `assets/` but are not loaded by the current site.
